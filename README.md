# 2026-SMT-Data-Challenge
This repository contains the abstract, paper, and final code of my project from the 2026 SMT Data Challenge, GO TIME. This project is the result of a group effort with Benjy Baronofsky and Jonathan Paris.

The outcome of a baseball game is often decided by inches. When a runner on third base tags up, beating the throw home requires more than raw speed, it requires a split-second reaction. In this repository, we uncover the hidden race before the sprint, translating a runner’s reaction time into a dynamic new metric: GO TIME.

All data used for this project was provided by SMT (SportsMEDIA Technology).
